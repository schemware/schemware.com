# schemware.com

The one-page website of Schemware, LLC, served by GitHub Pages at https://schemware.com.

- `index.html`: the home page.
- `sheepshead/index.html`: the Five-Handed Sheepshead coming-soon page (`/sheepshead/`).
- `styles.css`: shared styles; colours follow the Sheepshead iOS palette (`Assets.xcassets/Palette`).
- `AGENTS.md` / `CLAUDE.md`: identical instructions for coding agents, including the commit-to-`main` process.
- `images/`: the Sheepshead app icon at web sizes, plus the favicon and Apple touch icon.
- `CNAME`: the custom domain for GitHub Pages.

DNS is at Hover: four A records for `@` (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) and a CNAME `www` → `schemware.github.io`. The MX and SPF records are ImprovMX's (mail forwarding) and are left alone.
