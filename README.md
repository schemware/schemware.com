# schemware.com

The one-page website of Schemware, LLC, served by GitHub Pages at https://schemware.com.

- `index.html`: the page.
- `CNAME`: the custom domain for GitHub Pages.

DNS is at Hover: four A records for `@` (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) and a CNAME `www` → `schemware.github.io`. The MX and SPF records are ImprovMX's (mail forwarding) and are left alone.
